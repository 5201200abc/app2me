# 原发行方专属集成与品牌清理

## 产品规则

- 移除原发行方的登录、预置模型、订阅、计费、网关、遥测、品牌主题和专属图标入口。
- 删除已无运行入口的旧账号及套餐实现，不保留可被重新装配的网络客户端。
- 用户自行配置的 API Provider、第三方 MCP OAuth、本地模型和现有会话继续由其当前服务所有者管理。
- 历史账号配置不能进入模型执行目录；删除品牌类型后由配置 schema 和模型执行准入拒绝不受支持的访问方式。
- 不删除或改写用户数据库、会话、第三方凭据，也不改写 Git 历史。
- 已发布安装包撤回为草稿；本次清理不自动发布新安装包。
- 原作者及第三方许可证声明依照原始许可保留，不能通过更换应用名称改写权利归属。

## 所有者与验证

Provider Registry 管理用户模型配置，通用凭据服务管理第三方认证，Main 管理平台能力，发布脚本管理发布状态。删除专属业务状态和入口，不新增替代状态或写入路径。

验收覆盖源码及资产残留检查、第三方模型与 MCP 配置验证、历史无效访问方式的拒绝、类型检查、Lint 和架构检查。公开发布数量应为零，资产仍保留在草稿中。
