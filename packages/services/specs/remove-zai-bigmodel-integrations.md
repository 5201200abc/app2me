# 移除 z.ai 与 BigModel 集成

## 产品规则

1. 应用不再主动请求 z.ai、mycode.z.ai、bigmodel.cn 等原有官方服务，也不展示其登录、模型、订阅、计费和升级入口。
   不再保留未挂载的 Z.ai／BigModel OAuth 与 API Key 欢迎页实现。
   启动流程不再恢复旧 OAuth 会话或迁移旧账号提供商域。
   Web 不再连接 `?remote=` 桥接入口，Server 不再暴露 Web 远控创建与桥接端点；Desktop 本地与 SSH 工作区链路保持可用。
   Web 不再展示依赖官方 OAuth 的分享页登录；公开分享预览保持可读。
2. 用户已配置的第三方或本地 API 提供商继续由现有 Provider Registry 运行；旧任务数据仍可读取，不在移除集成时删除用户会话或凭据文件。
   历史 `zhipu-account` 配置不进入可选模型目录或执行 Registry。
3. 插件排序按本地确定性规则展示；官方插件清单由打包资源提供，个人市场仍按用户声明的来源运行。
4. 已退役的客户端配置 RPC 不再注册或发起请求；本地插件页不依赖远端配置才可打开、搜索和刷新。
5. 原客户端场景接口退役后，推荐提示词与自动化模板使用现有空目录行为；手动创建自动化仍可使用，不再访问官方场景服务。
6. 动态工作流可用性只接受本地运行时配置；不再从官方 client/configs 拉取灰度快照。
7. 闲时任务配置也只读取本地运行时配置与当前模型选择，不再访问官方 client/configs。
8. 退役订阅的静态商品目录返回空结果，Start Plan 预览返回空值；旧 client/configs 不再是应用运行时数据源。
9. 设置中的使用统计只展示本地会话统计；不再查询或展示原账号 Coding Plan 额度与商品。
10. 侧栏头像菜单保持语言、主题、界面模式、缩放和本地使用统计入口；不再依赖旧账号状态，不展示登录、退出、套餐徽标或升级入口。
11. 对话发送不再读取旧套餐身份、额度和升级状态；模型与工具错误沿用普通错误提示。
12. 旧订阅 RPC 保留明确的退役错误以兼容历史客户端请求；商品与企业定价返回空目录，本地动态工作流和闲时配置保持本地解析。任何购买、支付、订单请求不得访问旧官方接口。
13. 应用启动不再挂载旧购买面板；自动化页只提供定时自动化，旧闲时任务与 Coding Plan 准入入口不再展示或轮询。
14. Root 不再向工作区传递旧账号和退出登录操作，也不保留会调用官方 OAuth 退出与清理 WebView 的用户操作入口。
15. Host 不再向 Agent 提供旧官方 MCP 的账号身份头或受信来源配置；旧请求在 Agent 既有缺省拒绝边界中结束。
16. Provider Runtime 使用内置空账号来源，不再构建、刷新或向 Agent 注入 z.ai／BigModel 账号 Overlay；本地与个人 API Provider 继续按本地配置解析。
17. 原会话分享发布和导入依赖旧官方 API；顶栏不再展示分享发布入口，Host 对历史分享 RPC 明确返回功能不可用，Web 公开分享预览页仍可只读打开。
18. Host 不再实例化或启动旧闲时任务同步器，不再给 Agent 装配闲时工具服务；历史闲时 RPC 不得触发旧官方请求。
19. 本地与 SSH Host 的旧 OAuth 服务只保留协议兼容的空响应与退役错误，不发起登录、刷新或回调换票请求。
20. Agent 模型网络出口不再把 z.ai／BigModel 端点改写到旧 MyCode Coding Plan 网关；本地及用户自定义提供商继续使用统一代理传输。
21. 桌面遥测不再读取旧 OAuth 用户信息、JWT 或登录归因，也不向旧官方遥测端点上报；本地生命周期统计保持可用。
22. 旧官方反馈工单、社区和账号命令不再出现在应用入口；历史反馈 RPC 明确拒绝且不读取 JWT 或发送附件，产品文档仍指向仓库 README。
23. CLI/TUI 不再展示或执行 z.ai／BigModel 的 `/login`、`/logout` 与 Coding Plan API Key 流程；无可选模型时提示配置本地或个人 API 提供商。
24. 独立 CLI 的 Provider Registry 只读取随应用提供的 Built-in 和个人配置，不刷新旧官方 Built-in，也不读取共享账号凭据或接受旧账号 Overlay；托管 Agent 对历史账号同步请求明确拒绝。
25. 模型执行适配器拒绝历史 `zhipu-account` 与 `zhipu-coding-plan-api-key` 配置，防止旧会话或手工配置绕过空账号来源发起官方请求；普通 API Key Provider 保持可用。
26. Root 不再把全局 Store 初始化为“正在恢复 OAuth”；首次渲染无需等待已移除的账号登录恢复。
27. 通用共享凭据存储保留第三方 MCP 凭据能力，但不再暴露 z.ai／BigModel 专用键名及登录凭据读写接口。
28. Desktop 的通用外部链接 IPC 不再为旧 Coding Plan 购买、PayPal 和支付回调保留特殊 WebView 跳转；合法外部链接仍由系统浏览器打开。
29. Desktop 的 WebView 只装配通用浏览器 preload 和 popup 规则，不再识别旧 Coding Plan 官网、装配购买桥或让支付页面继承特权 preload。
30. 原自动更新 Manifest 默认指向旧 z.ai 服务；未配置替代更新源时不启动自动更新检查，开发环境显式设置的更新源仍可用于联调。
31. 构建环境和 Desktop 子进程环境不再注入旧 z.ai／BigModel OAuth、业务 API 或客户端 ID；只透传仍用于本地配置的显式产品端点。
32. 通用模型请求不再附带旧 z.ai 默认 Referer 或 GLM Agent 身份头；个人 Provider 仅接收通用客户端和平台标识。
33. Agent 不再为普通 MCP 连接池装配旧官方身份头端口及 z.ai 可信来源；第三方 MCP 的连接和自身 OAuth 保持可用。
34. Host 启动 Agent 时不再注入旧产品 API origin；网络代理、CA、工作区身份与 CUA 环境仍按既有边界注入。
35. 订阅兼容服务只返回本地静态配置和退役错误，不构造 BigModel／z.ai 网络 Provider 或产品 API Client；本地动态工作流和闲时 Mock 解析结果维持原有规则。Desktop 注入的通用网络传输继续用于 SSH 远端资源获取，并由 ServiceCollection 释放。
36. 不再保留未被服务装配的 BigModel／z.ai 支付 Provider 实现；历史协议类型可保留以让旧客户端得到明确退役错误。
37. 不再保留历史团队密钥投影及账号鉴权头构造入口，旧调用方不能继续向旧官方 API 发送请求。
38. 历史账号可用性查询只返回“未连接”，不再执行 BigModel／z.ai 权益、余额、订阅或套餐校验请求。
39. Desktop 帮助菜单不再展示指向旧官方站点的 What's New 和产品端点切换；历史命令不得再打开旧 changelog 或把设置指回 z.ai。
40. 打包版 Desktop 启动不再访问旧官方客户端配置执行强制更新 Gate；在没有替代服务时继续打开本地窗口。
41. 架构不匹配提示保留诊断信息，但不再提供指向旧 z.ai 官网的下载按钮。
42. Web 和 Desktop 平台的历史反馈与社区能力返回不可用，不再解析或打开默认旧官方社区 URL。
43. Web 构建不再代理旧 OAuth 换票接口或注入旧 OAuth 客户端参数；没有显式私有部署地址时，浏览器包不携带旧官方默认域名。
44. Desktop 灰度配置使用本地禁用值，不再在启动与刷新时读取旧官方客户端配置；历史帮助配置读取器不再装配。
45. 共享产品端点的默认值指向本地服务，历史 z.ai／BigModel Provider 家族不再提供可点击的官方购买 URL；旧账号服务不再从 Node 公共入口装载。
46. 旧配置迁移在解析前按 Provider ID 过滤 z.ai、BigModel 和 GLM 预置项，保留其他个人 Provider；没有配置 SSH 资源 CDN 时，开发态使用当前版本本地资源，生产包使用随包的当前版本远端组件。
47. 旧 OAuth 换票、用户信息、凭据仓库和 BigModel 用量 Provider 不再保留可加载实现；Host 仍以退役 OAuth 协议桩回应历史调用。
48. 桌面打包前生成当前版本远端资源，只把四个平台清单及其引用的组件装入包内；清单版本与平台不匹配或组件缺失时打包失败。
49. 模型设置页只隐藏历史 z.ai／BigModel 预置 Provider 与模板，其他个人 Provider 和模板仍可查看及编辑。
50. 无引用的 BigModel 团队密钥、权益、订阅与额度映射实现删除，历史调用仍由退役服务边界拒绝。

## 状态所有者与事件顺序

```text
用户 Provider 配置 → Provider Registry → Agent 模型选择与执行
打包插件目录 → Agent 插件清单 → Plugin Management RPC → 插件页
个人插件目录 → Agent 刷新结果 ───────────────┘
```

旧数据中的历史提供商 ID 只用于兼容读取，不可触发已退役服务的联网调用。

## 验收

1. 离线启动并打开插件页，不出现对原官方域名的请求或 `fetch failed`；默认目录、个人来源、已安装插件保持可用。
2. 模型列表、登录页、设置、订阅和升级入口不再出现 z.ai／BigModel／GLM 项。
3. 本地或用户自定义 API 提供商仍可选、可发起会话；旧任务可以打开。
   历史账号提供商模型不可选、不可执行。
4. 打开会话草稿和自动化页不会请求原客户端场景接口；自动化手动创建入口仍可见。
5. 启动与刷新动态工作流可用性时，不请求官方 client/configs。
6. 打开闲时任务或刷新其配置时，不请求官方 client/configs。
7. 读取旧商品目录和 Start Plan 预览时不请求官方 client/configs，也不展示可购买商品。
8. Web 的 `?remote=` 与旧 OAuth 回调不会发起远控或登录；Server 的 `/api/connect-remote` 与 `/ws/remote/:id` 不再提供服务；Desktop SSH 与普通 Web 工作区、公开分享预览仍可打开。
9. 打开设置的使用统计仅访问本地 App Usage；不会发出 z.ai／BigModel 订阅、权益或额度请求。
10. 未登录与带有历史登录缓存的状态均可打开侧栏偏好菜单，且菜单不显示旧账号操作。
11. 打开或发送对话时不请求旧账号额度，不显示 Coding Plan 横幅或升级动作，普通错误仍可关闭。
12. 调用旧购买、支付和订单方法会明确失败且没有网络请求；读取商品和企业定价会得到空目录。
13. 启动、打开自动化、刷新自动化时没有旧购买面板的权益查询，也没有闲时任务 API 请求；定时自动化仍可查看和创建。
14. 设置与侧栏均不展示旧账号资料或退出操作；通过普通工作区导航不会触发 OAuth 服务。
15. Agent 请求旧官方 MCP 身份头时不能从 Host 获得 z.ai／BigModel 凭据。
16. 启动、设置更新与模型目录刷新不会触发账号 Provider 的远程资格校验，旧账号模型不进入可选目录。
17. 对话顶栏没有旧分享按钮；历史分享 RPC 不发起旧官方请求，公开预览页仍可读取已有内容。
18. 启动 Host 与打开对话均不启动闲时同步或申请票据，Agent 无旧闲时工具服务。
19. 旧 OAuth RPC 返回空登录态，尝试发起登录得到明确退役错误且无网络请求。
20. Agent 发起普通自定义模型请求时，传输层不会再改写到旧网关域名。
21. 即使环境中仍保留旧遥测端点配置，启动和会话事件也不会读取 OAuth 凭据或向该端点发送请求。
22. 帮助菜单与命令面板不显示旧工单、社区、登录或退出操作；历史反馈 RPC 不联网。
23. CLI 正常提示词不会因旧账号缺失而进入登录门槛；旧登录命令为未知命令且不触发浏览器或鉴权请求。
