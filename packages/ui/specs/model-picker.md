# 模型与思考选择器

## 产品规则

- 聊天工具栏采用圆角胶囊；模型菜单为紧凑单层列表，模型右侧显示当前选中标记，不再要求展开供应商二级菜单。不同供应商用弱化分组标题区分。
- 思考浮层采用紧凑布局，保留居中档位与模型名称、右侧重置、橙色分档轨道和白色滑块。
- Qwen3.8-27B 滑杆只能落在 low、medium、xhigh 三档，默认/重置 xhigh；no thinking 是独立开关，不是第四个 effort。
- 其他本地模型仅 thinking/no thinking，不虚构强度档位。所有值来自 Host 发布的 optionSpec，不能由展示样式改写请求值。
- 指针、触屏、方向键/Home/End 均能选档；Esc 关闭，桌面恢复输入焦点，手机不强制拉起键盘。恢复中的禁用状态继续有效。
- 宽度不超过视口，浅色/深色主题使用语义表面；专用橙色只用于强度强调。

## 状态与事件

Composer 是下一次请求中模型/思考选择的唯一所有者。浮层只持有开闭状态；滑动或点击产生既有 onValueChange，Composer 冻结选择后沿现有 Submission/Host/CLI 路径发送。切换模型始终重新核对其真实档位。

## 验收场景

1. 一次打开模型菜单即可看见全部可选模型；选择项与勾选标记一致。
2. Qwen 三档滑杆的键盘、点击切换值为 low/medium/xhigh，重置回 xhigh；关闭项发送 disabled。
3. 非 Qwen3.8-27B 本地模型只展示 thinking/no thinking。
4. 手机窄屏可完整操作；Esc 与焦点恢复保留；刷新后已保存选择不改变。
