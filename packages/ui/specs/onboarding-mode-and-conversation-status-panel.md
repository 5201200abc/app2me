# 模式引导与会话状态面板

## 产品规则

- 首次使用或从设置主动打开引导时，只展示 UI 模式选择。职业选择与助手偏好页不再出现。
- 模式选择页不显示右侧品牌视觉，选项和操作位于页面中央。
- 选择编程或办公模式后保存模式并结束引导。跳过时保持当前模式并结束引导。
- 移除的职业与偏好问题在引导记录中写 `null`；已有设置中的记忆和主动推荐开关不因本次引导改变。设置中的 `onboardingOccupation` 仍作为旧版首跑判定的完成标记，使用 `other`。
- 引导记录写入失败不重新遮住当前会话；已有记录仍能预填模式。用户主动关闭时不保存。
- 状态面板在助手回答期间自动展开，本轮结束后收起；用户也可手动展开或收起。在宽度至少 640px 的会话中，展开面板位于问答右侧且消息列让位。在更窄的会话中，面板占据正常布局高度，不覆盖消息或输入区；内容过长时在面板内部滚动。

## 所有者与接口

- `OccupationOnboarding` 持有当前模式选择与保存状态，经既有 settings 与 onboarding record 服务写入。
- `SessionPane` 持有状态面板的显示模式；`ConversationStatusPanel` 依据 `layoutMode` 决定位置。Git 数据与操作仍来自现有 Git 回调。
- 不新增持久化字段、协议或跨模块写入路径。

```text
模式选择或跳过 → OccupationOnboarding → 当前模式（仅选择时）
                                    → settings 完成标记
                                    → onboarding record 追加
                                    → 本会话标记已完成

回答阶段或手动展开状态面板 → SessionPane 显示模式 → ConversationStatusPanel 布局
                                      ├─ 窄会话：正常文档流
                                      └─ 宽会话：浮动，消息列让位
```

## 验收场景

1. 清除首次引导记录并打开 Web 或 Desktop：只看到模式选择，职业与偏好页均不可达。选择模式后进入工作区，再打开设置中的引导仍只看到模式选择。
2. 跳过模式选择：原模式、记忆和主动推荐设置不变；记录中的职业、模式、记忆、主动推荐均为 `null`。
3. 在宽度小于 640px 且有 Git 更改的会话中点开状态面板：面板显示 Git 工具，问答和输入区仍可见且可点击。收起后会话恢复原布局。
4. 在宽度至少 640px 的会话中展开面板：消息列让位，面板不覆盖问答。回答时自动展开，停止或完成后收起；切换会话不继承上一轮的展开状态。
