# 会话状态面板

## 产品规则

- 模式选择引导已移除；界面统一采用编程行为，无办公模式入口或持久化状态。历史引导记录读取时剥离退役字段，职业、记忆等独立字段仍兼容。
- 状态面板在助手回答期间自动展开，本轮结束后收起；用户也可手动展开或收起。宽度至少 640px 时面板位于问答右侧且消息列让位，窄会话中占据正常布局高度。
- Git 工具与终端入口始终遵循原有平台和项目权限，不由界面模式限制。

## 所有者与接口

SessionPane 持有面板显示模式，ConversationStatusPanel 依据 layoutMode 决定位置，Git 数据和操作来自现有回调。窗口及模式清理规则见根目录 specs/compact-window-and-mode-removal.md。

## 验收

1. 设置与账号菜单不包含界面模式，旧模式记录不影响布局或工具入口。
2. 窄会话展开 Git 面板时问答和输入仍可见可操作；宽会话展开时消息列让位。
3. 回答时自动展开，停止或完成后收起；切换会话不继承上一轮展开状态。
