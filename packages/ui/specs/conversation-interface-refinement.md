# 会话界面精简

## 产品规则

1. 会话状态面板在助手回答期间自动展开；本轮结束后自动收起为小胶囊。用户仍可手动展开或收起，用于查看 Git 与后台任务。展开内容在问答右侧，不遮挡消息或输入区；窄手机视口允许占据顶部文档流。
2. UI 模式引导不显示右侧品牌视觉；模式选项、说明和操作在整个页面水平与垂直居中。
3. 界面字号只能在 11、12、13 px 之间选择，使用上下按钮逐级调整；旧设置值读取时归一化。代码字号继续使用独立设置。
4. 未登录侧栏底部不显示“连接使用”头像入口；头像菜单也不显示“连接使用”操作。已有设置入口保留。
5. 聊天模型选择弹层使用紧凑宽度、行高、内边距与圆角，保留分组、选中状态、模型管理和键盘操作。
6. 思考选择弹层使用紧凑宽度、控件和内边距，保留真实档位、禁用态、重置及焦点恢复。
7. 会话时间线的工作时长和思考摘要始终用英文显示，中文界面也使用英文缩写单位；其他界面继续遵循当前语言。

## 所有者与事件顺序

```text
runtime SessionControl.phase ─→ SessionPane 派生回答中/已结束
                              ├→ 会话状态面板显示模式
                              └→ ConversationTimeline 消息列宽度与让位
用户点击胶囊/收起按钮 ────────→ 当前会话的手动显示选择

字号按钮 ─→ uiFontSize store ─→ 本地存储 + 跨窗口广播 ─→ --ui-font-size
```

- 会话状态事实只来自当前会话的 `snapshot.control.phase`；不按 Git 有无更改推断回答状态。切换会话不得继承上一轮自动展开。
- 模型和思考弹层只改样式，不改选择值、请求协议或保存路径。

## 验收场景

1. Git 有更改但会话空闲时，右侧只显示小胶囊。发送问题进入回答后自动展开；回答完成后自动收起。展开时消息和输入区仍可点击。
2. 窄桌面会话里，展开面板位于问答右侧；手机窄屏里问答保持可读。
3. Web 和 Desktop 打开模式引导，视觉右栏消失，模式选项位于全屏中心。
4. 字号在 11、12、13 px 边界点击上下按钮，无法越界；刷新后旧的 20 px 记录归一化为 13 px。
5. 未登录侧栏既没有“连接使用”主项，也没有同名菜单项；设置齿轮仍可用。
6. 模型、思考选择弹层在桌面和手机可完整操作；选中、重置与焦点行为不变。
7. 中文界面的已工作、工作中和思考摘要显示英文，工作时长为 `6s` 等紧凑单位。
